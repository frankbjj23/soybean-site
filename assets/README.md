# Asset provenance

The logo, Raleway fonts, curved arrow, and legacy images were provided by the original AgroExpress site and retained from the existing repository.
On November 16, 2026, the logo's company suffix was removed by a precise transparent-pixel edit approved by the owner. All remaining original artwork is unchanged; AI-generated alternatives were not used.
agroexpress-logo-small.webp and soybean-field.webp are optimized versions of existing assets.

Generated November 15, 2026 using OpenAI image generation:

- soybean-landscape-640.webp / -1280.webp: illustrative soybean growing landscape.
- soybean-harvest-640.webp / -1280.webp: illustrative harvested soybean seeds and pods.
- corn-harvest-640.webp / -1280.webp: illustrative maize cobs on the plant.

Generated images are representative crop illustrations, not photographs documenting AgroExpress facilities or a specific shipment.
The old soybeans-close.jpg image depicts a different grain and is no longer used.

Icons in icons/ come from the lucide-static package. See icons/LICENSE.
